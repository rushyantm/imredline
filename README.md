# IMRedline

Point at anything on a live website, say what's wrong, and it lands as a GitHub issue — screenshot, pinned element, attachments and all — where a person or an AI agent picks it up and fixes it.

One package. Installs the same way on every site. Reviewers need no account.

**Status: pre-release, private.** Being extracted from four production copies (Nutrition Nest, EIPL Energy, PEMA Wellness, Aradea / Pebble Beach). Public at v1.

Community-supported. MIT.
